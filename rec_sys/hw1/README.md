# Поиск похожих товаров и пользователей

Streamlit-приложение вычисляет косинусное подобие между товарами и пользователями по матрице предпочтений и выводит две самые близкие пары.

Матрицу можно:

- заполнить вручную в таблице;
- загрузить из файла `.txt` или `.csv`.

Строки матрицы соответствуют товарам, столбцы — пользователям. Допустимые рейтинги: от `0` до `5`. В файле значения можно разделять пробелами, табуляцией, запятыми или точками с запятой.

## Запуск

Перейдите в папку проекта:

```bash
cd /Users/andrejsuhanov/Applications/MISIS/rec_sys/hw1
```

Создайте и активируйте виртуальное окружение:

```bash
python3 -m venv venv
source venv/bin/activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

Запустите приложение:

```bash
streamlit run app.py
```

После запуска откройте в браузере адрес `http://localhost:8501`.

## Формат файла

Пример содержимого файла:

```text
5 4 5 3 5
5 5 5 3 5
5 4 4 2 5
5 3 5 0 3
5 0 5 0 0
4 5 5 3 1
```
