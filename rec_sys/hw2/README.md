# ДЗ 2 — Кластеризация по косинусному подобию

## Запуск

Из корня `rec_sys`:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r hw2/requirements.txt
python -m streamlit run hw2/app.py
```

Откройте адрес, который выведет Streamlit (обычно http://localhost:8501).
Для запуска только расчёта примера: `python hw2/task2.py`.

## Интерфейс

- Слева задаются число объектов (2–12), матрица сходства и порог R.
- «Создать матрицу» создаёт нулевую матрицу выбранного размера.
- «Пример задания» восстанавливает исходные пять объектов и R = 0,85.
- Вводятся только элементы над диагональю. Нижняя половина отражает их автоматически.
- Справа выводятся исходная матрица, все промежуточные матрицы, причина остановки и итоговые группы.
- При изменении матрицы или порога предыдущий результат убирается: нужно выполнить расчёт заново.

## Алгоритм

Каждый объект первоначально образует отдельный кластер. На каждом шаге выбирается
пара разных кластеров с максимальным сходством. Если максимум не меньше R,
кластеры объединяются. Для новой матрицы сходство групп A и B вычисляется как
`S(A, B) = max(S(i, j) для i из A, j из B)` по исходным данным.
Это метод ближайшего соседа (single linkage для сходств). Диагональ равна нулю
и не участвует в выборе пары. При равных максимумах выбирается первая пара
по порядку строк. Расчёт заканчивается, когда максимум меньше R или остаётся один кластер.
При R = 0 объединяются все объекты, в том числе с нулевым сходством.

На вход подаётся готовая симметричная матрица косинусного подобия в диапазоне [0; 1],
как в задании. Повторно вычислять косинусы по этой матрице не требуется.

Пример при R = 0,85:

1. U1 + U2 при сходстве 0,95.
2. {U1, U2} + U3 при сходстве 0,90.
3. {U1, U2, U3} + U4 при сходстве 0,85.
4. Остановка: 0,80 < 0,85. Итог: {U1, U2, U3, U4} и {U5}.
